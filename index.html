Notes

          
Important usage notes

          

            This site runs entirely in the browser. Users should provide their own
            RapidAPI key when generating schedules.
          

          

            The preview tables show the first portion of the generated output for quick
            checking. The full result is included in the downloaded CSV.
          

          

            The default builder accepts either ICAO or IATA airport codes. The time-based
            builder should use ICAO only.
          

        


        

          
Recommended workflow

          
    
            
  • Generate the default schedule first for your base route set
    • 
            
  • Use the time-based schedule when exact movement timing is needed
    • 
            
  • Download the exported CSV file
    • 
            
  • Apply custom stand-tag rules using the stand-tag applier
